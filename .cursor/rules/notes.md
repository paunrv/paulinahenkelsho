# Notes System

Writing is part of the product.

## Purpose

Notes is a personal knowledge library — not a blog.

Two categories:

- **Building** — product articles structured as Problem → Discovery → Thinking → Decision → Reflection
- **Field Notes** — observations from life; never force a product lesson

## Content location

Markdown files live in `content/notes/`.

Templates:

- `content/notes/_template-building.md`
- `content/notes/_template-field-notes.md`

Editorial guide: `content/notes/README.md`

## Frontmatter

```yaml
title:
subtitle:
category: Building | Field Notes
date: YYYY-MM-DD
readingTime:
featured: true|false
published: true|false
tags: []
```

Set `published: false` for drafts. Drafts do not appear on the site.

## Writing rules

- Answer: “What made me stop and pay attention?”
- Short paragraphs, silence, trust the reader
- No CTA, no Lessons Learned, no SEO bait
- If a story is powerful: remove instead of adding
